# NayaDrishti AI — starter prototype

This is a small private research-drafting prototype, not an automated news publisher.

## Run locally
1. Install Python 3.11+.
2. Run `pip install -r requirements.txt`.
3. Set environment variables from `.env.example` in your terminal or hosting dashboard.
4. Change `ADMIN_PASSWORD` and `FLASK_SECRET_KEY` before exposing the app.
5. Run `python app.py` and open `http://127.0.0.1:5000`.

## Important
- Never put API keys in source code, GitHub, screenshots, or chat.
- OpenAI API usage may require billing and is separate from ChatGPT.
- The app only drafts research. A person must verify claims, source links, image rights, and context before posting.
- This starter does not read Facebook pages, monitor RSS feeds, generate images, or publish to Facebook/Instagram.
- Do not scrape sites or bypass platform permissions. Use authorised feeds and official Meta APIs only.
- A free hosting service may sleep; it cannot guarantee continuous monitoring.
